This directory is for non-destructive **working media** used by the 0:00–0:15 cinematic hook.

- Master / supplied working exports remain in `2-first 15 seconds/`.
- Do not move, rename, overwrite or destructively trim the source files.
- The numbered folders correspond to editorial roles, not final timeline order guarantees.
- Do not duplicate a source just because it is shortlisted for more than one role.
- Only one committed proxy currently exists: the 1080p H.264 competition proxy created from the decode-heavy 4K HEVC source.
- Candidate source ranges and technical metadata live in `src/data/hook-assets.ts`.
- Human-readable decisions live in `HOOK_ASSET_REPORT.md`.

No final hook timing or edit is defined by this folder structure.
